## Checks before each manual merge

1. Read current main, PR head/base, state, draft flag, checks and review threads.
2. Verify intended earlier heads are ancestors of main. If any participant changed a branch, inspect and rerun relevant checks rather than overwriting.
3. Set base=main for the current next PR only; inspect that its diff is the expected feature delta. Do not force push to rewrite an author's history.
4. Read current-head CI. Historical79 CI or a previous different head is not evidence for this PR. workflow_dispatch checks were explicitly run at each split head because ci.yml's PR trigger filters main.
5. Satisfy repository review requirements with a qualified non-author, resolve actual threads, then the human selects Create a merge commit.
6. Confirm merged state and recorded merge SHA before telling anyone it is merged. No automatic destructive rollback of migrations.
