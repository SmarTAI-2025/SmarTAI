## Merge / retirement procedure

1. Publish candidate with current body and evidence. If main advanced, merge it locally, inspect altered paths, rerun affected tests and update exact SHA/evidence before pushing.
2. Obtain required current-head approvals; latest push can invalidate earlier approvals.
3. Human merges the single candidate into main, preferably a merge commit preserving ancestry.
4. Read back main and confirm candidate ancestry. Only then retire old #40/#58/#59 and any #60–#67 still open with an explanatory link. A closed superseded PR is not falsely reported as directly merged.
