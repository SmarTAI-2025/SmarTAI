# 登录闲置与编辑冲突修复（2026-10-04）

来源：[修复登录过期与会话提示](codex://threads/01a10772-8c92-77a0-90b1-c70012ac13f6)。用户要求约 30 分钟无操作退出，持续操作续期，并全面检查同类版本误判。

## 登录

- 登录签发的 access token 绑定持久 refresh session；默认闲置上限 30 分钟。旧的 JWT 短时限配置不会缩短新会话窗口；调整闲置策略时需同步后端 `session_idle_minutes` 与前端 `SESSION_IDLE_MS`。
- 真实输入触发 `/auth/activity`，同一页面按一分钟间隔节流，使用仍有效的 Bearer 凭证，Cookie 被屏蔽时也能续期。路由切换保留尚未发送的活动。
- 后台轮询、聚焦和 Cookie 恢复不延长闲置时限。过期、注销、密码重置或账户停用不能通过活动接口复活。
- 有效旧 JWT 可在活动时迁移；不要求升级后立即重新登录。公共和私有管理员作用域保持独立。
- 确认 401 或闲置到期后，先发布失效状态再清除凭证和草稿，路由阻塞器必须让出登录跳转。网络错误/503 保留当前工作区。

## 编辑边界审计

任务总版本用于后端提交时的并发校验；本地编辑版本统一由 `frontend/app/src/lib/editorVersions.ts` 选择相关业务字段。没有删除后端 CAS，也不会自动重试收费或有副作用的操作。

| 流程 | 本地冲突依据 | 不应触发冲突的变化 |
| --- | --- | --- |
| 新建/编辑任务信息 | 已有任务元数据签名，保持原行为 | 无关的任务工作流变化 |
| 题目上传 | 课程、题目内容、题目来源/任务 | 加入知识库、状态轮询、总版本 |
| 作答上传 | 课程、题目匹配内容、当前作答/来源 | 知识库、复核标志、状态轮询 |
| 资料导入设置 | 课程与目标题目内容 | 总版本、知识库数量、进度 |
| AI 补全选择 | 缺失目标集合 | 总版本和返回顺序 |
| 资料匹配复核 | 计划内容、候选项与目标字段 | 总版本和候选返回顺序 |
| 批改配置 | 实际配置、模型可用性/身份 | 知识库增删、readiness、总版本 |
| 资料库元数据 | 文件名、课程、分组、分类、标签 | 引用次数、解析状态、时间戳 |
| 题目字段/评分、学生身份/答案、成绩复核 | 已有当前字段/记录版本，保留 | 其他题目或任务总版本 |
| 分析图表、管理员业务配置 | 正式结果版本、配置版本，保留 | 不能以任务总版本替代它们 |

真正冲突时提供“保留当前输入”及“核对后恢复旧草稿”，均不自动提交。上传/导入等下一步依赖查询结果的操作等待缓存刷新；逐条题目、作答和身份复核已有完整响应，立即同步字段与版本，不等待慢速后台读取。重置草稿也持有写入锁至 IndexedDB 删除及版本读取完成，防止自身删除和新暂存互相冲突。

此前“上传题目并存资料库”的修复位于共用 `_source_fingerprint`：上传后生成的资料库 ID 不属于原始输入身份；从资料库选择时该 ID 仍参与校验。对应四项现有回归本次重新通过，与本次编辑版本问题分别验证。
