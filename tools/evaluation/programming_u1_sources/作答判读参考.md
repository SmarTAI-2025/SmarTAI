# 39 份构造作答的判读参考

依据 U1 的九道题、评分规则、完整源码和故障情境，由 Codex 按教师角色逐份审读，供盲测后核对。真实任课教师的确认栏仍留空。评分模型只看原题、作答、教师规则和执行证据，不接收本表。允许合理的部分分差异；评测逐项检查根因有没有漏掉、有没有把正确行为说错、材料或平台问题有没有扣到学生头上。

| 作答 | 应当指出或认可的事实 | 应避免的误判 |
|---|---|---|
| S01-F01 | 滚动状态计算 Fibonacci，含 0、1，线性时间，符合题意。 | 因未建立数组而扣动态规划分。 |
| S02-F01 | 各项数值正确；朴素双递归重复计算，没有记忆化，违反线性时间及动态规划要求。 | 将小样例全过说成满足复杂度，或声称算错 Fibonacci 数值。 |
| S03-F01 | 只在 n=0 时返回 1，应返回 0。其余循环和方法成立。 | 对所有普通项或算法重复扣分。 |
| S04-F01 | 清单已确认缺交，可以记零分。 | 推测语法错误。 |
| S05-F01 | for 行缺冒号，代码不能运行；滚动状态与递推表达了正确思路，规则明确允许过程分。 | 把语法问题定性为算法错误，或声称已成功返回结果。 |
| S06-F01 | n=0 时除以零，其余项按正确的线性递推计算。 | 将特定输入的运行错误扩大到所有输入。 |
| S07-F02、S08-F02、S11-F02、S23-F02 | 正确累加每个正数，保留重复值；共享函数、顺序和合法 import 不影响结果。 | 把 helper 当答案，或声称求的是个数。 |
| S07-F03、S08-F03、S23-F03 | 正确统计每个严格正元素，排除 0，重复元素分别计数。 | 把求和函数的结果归给计数题。 |
| S09-F02 | set 去重，两个相同正数只加一次。对空列表、负数和互异正数的处理正确。 | 将错误说成没有排除负数。 |
| S10-F02 | 条件写成大于等于 0，但加上 0 不改变数值和，本题结果完全正确。 | 看到大于等于号便扣分。 |
| S10-F03 | 对计数题同一段 helper 会把 0 作为正数计入，其余正数及重复值的处理正确。 | 漏掉 0，或反过来把错误扣到 F02。 |
| S11-F03 | 整份文件只有求和，没有本题计数实现；确认归属后按缺本题作答处理。 | 拿另一题求和函数测试，或称整份文件未交。 |
| S12-F02 | 有可辨的求和、计数逻辑，但函数名与指定接口不符且映射待核。应先复核题目归属与入口。 | 按定义顺序猜测或直接认定求和错误。 |
| S13-S01 | 跨行、空白、负数和 n=0 均正确，输出只有和。 | 要求题目未规定的非法输入处理。 |
| S14-S01、C02、X02 | 对元素取绝对值后累加，遇负数出错。如 n=1、值为 -2，应为 -2，实际为 2。题目有结果门槛。 | 因若干测试通过按通过率给分。 |
| S15-S01 | 求得的数值正确，但输出多了 sum =，违反只输出数值的要求。 | 把格式错误说成加法算错。 |
| S16-S01 | print 调用缺右括号，解析失败。 | 将错误归因给输入或执行平台。 |
| S17-S01 | 代码本身正确，指定情境是平台执行失败，保留未评分、允许重试。 | 给学生零分或说代码超时。 |
| S18-S01 | 输入的正确和为 6，资料误填 7。保留原预期，请教师核对后再评。 | 改学生代码、改教师预期，或用错误的 7 扣分。 |
| S19-F02、S19-F03 | 题号注释与函数作用相互冲突，两项均须核对归属；算法各自可辨。 | 用注释优先或出现顺序静默分配并给分。 |
| C01、X01 | 单文件程序读取 n 个整数，逐项累加，宽整数足以容纳全部合法输入，输出正确。 | 声称存在本题范围内的溢出。 |
| C03、X03 | 累加语句末尾缺分号，学生源码编译失败。 | 声称编译器不可用，或仍有成功运行的测试。 |
| C04、X04 | 样本明确缺交，无需启动编译器。 | 将缺交算作编译失败。 |
| S20-F04 | 指定名称 add，接收两个位置参数，返回其和。 | 对风格或负数输入无依据扣分。 |
| S21-F04 | 求和正确；题目明确要求 add，提交却名为 combine。接口部分应由教师按规则核对。 | 自动改名宣称原提交全对，或把接口错误说成加法错误。 |
| S21-F05 | 同一份 combine 代码对这一道未指定函数名的题完全正确。 | 沿用上一题的 add 命名要求。 |
| S22-F04 | 代码对一对数求和的逻辑正确；add 只接收一个 pair，违反两个位置参数的要求。 | 强行改为单列表调用后视为合规，或将算法判错。 |
| S24-S02 | 从标准输入读取两个整数，仅输出其和及换行，符合题意。 | 因没有名为 add 的函数而扣分。 |

核对时先独立阅读模型评语与分项，再对照本表。一份作答可能含不同题目的记录，应按作答编号逐项统计。平台故障、题目归属待核和错误预期单列；对于这些场景，正确的复核或重试决定本身就是验收结果。
