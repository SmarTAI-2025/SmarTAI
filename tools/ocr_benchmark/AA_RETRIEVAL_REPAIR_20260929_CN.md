## 本轮修复

1. **一般化检索**：复用 BM25，增加 Snowball 英文词干、短段落匹配、保守的章节/题号结构提示及有明确连续证据的跨页续题。原文、公式和引用内容不改写；页号、段落位置、文件版本共同约束推断。缺页、章节切换、错误偏移、不同文档/版本均不能继承题号。
2. **版本兼容**：新索引为 `bm25-structure-stems-v3`。已经冻结的 v1/v2 批改保持原索引算法，不以新算法悄悄改变历史上下文。
3. **可选跨语言查询**：资料库默认本地零模型检索；教师明确选择已有私有模型后，只把查询发给该模型，最多两个同义/翻译查询，再用 RRF 合并本地结果。查询不是指令；保留公式、题号、数字和否定约束，异常回退本地并显式提示，不返回原始供应商错误。
4. **成本控制**：同一教师、任务、模型配置和问题复用查询计划；并发合并、30 分钟有界缓存、最多 640 请求输出 token、30 秒等待预算，不自动重试失败。输出 token/等待时间不是供应商硬保证，超时可能已计费。共享池不新增该调用，未选教材及旧索引任务不调用；40 份作答相同问题的测试只触发一次改写。前端显示本次调用数及复用状态。
5. **批改接线边界**：仅增强此前已用教材的证明/概念/客观题路径，使用已经选定/冻结的 provider；只改写题干，不把学生答案或教材传给改写调用。撤销资料或改变范围后丢弃旧结果。计算/编程教材片段接线仍未改，此前自动审批拦截尚未解除。
6. **后台费用防护**：认证、权限、地区、限额、模型不支持等明确供应商失败后暂停整书剩余页，不继续逐页发送同类失败请求。已读取文字保留，后续显式恢复。Google SDK 真实异常类型覆盖地区/密钥分类；不绕过地区限制。
7. **已有文字模式**：三个知识上传 API 支持 `native_only`，课程资料库提供未默认勾选的“仅提取已有文字（不调用模型）”。此模式不解析模型凭据，只读已有文字；图像和损坏文字仍标内容缺口，不谎报完整。原文件重复上传仍沿用原任务，不以重传静默变更已有任务配置。题目和学生作答的高精度标准没有降低。
8. **前端保真**：真实 AA 页面暴露 Markdown 重新从 1 编号的问题；已保留列表起始、跳号和重复号。引用预览不再先重复显示整段文字才显示 PDF；中文页状态和安全错误可读，“未完整识别”不再混同为完全不可检索。
9. **资源修复**：重复句子的初版压力样本掩盖了真实风险，新增不重复段落压力样本后发现索引 109,271,586 bytes 超过 96 MiB 缓存预算。改用紧凑不可变词项数组后为 33,196,050 bytes，保留全部 4,499,336 字符，不调高缓存限额或删除页面。
